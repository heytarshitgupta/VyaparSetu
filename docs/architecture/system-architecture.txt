2. CORE SUBSYSTEMS
------------------------------------------------------------
1. Presentation Layer: Flutter widgets utilizing Material 3, shared design tokens (AppTheme), responsive layout constraints, and accessibility wrappers.
2. State Management: Provider / ChangeNotifier patterns separating business logic from UI widgets.
3. Data Layer: Centralized Supabase service layer interfacing with PostgreSQL and storage buckets via typed data models.
4. Security and Authorization: Row Level Security (RLS) policies enforcing multi-tenant isolation directly inside PostgreSQL.
