1. SHARED ROLE ENTRY GATEWAY
------------------------------------------------------------
Implemented in lib/core/auth/role_selection_screen.dart:
- Displays high-contrast, low-literacy friendly cards for choosing between "I Want to Buy Products" (Buyer Portal) and "I Make & Sell Products" (Producer Portal).
- Root route ('/') loads RoleSelectionScreen.
- Buyer selection routes to '/buyer_auth' (preserving teammate's Buyer module 100% untouched).
- Producer selection routes to '/producer_login'.


2. SHARED AUTHENTICATION SERVICE
------------------------------------------------------------
Implemented under lib/core/auth/:
- AuthService (lib/core/auth/auth_service.dart)
  * Singleton wrapping Supabase Auth operations using SupabaseService.client.
  * Methods: signUpWithEmail, signInWithEmail, signOut, currentUser, currentSession, authStateChanges stream.
  * Uses the Supabase publishable key only. Zero service-role keys.

- AuthExceptionHandler (lib/core/auth/auth_exception_handler.dart)
  * Sanitizes Supabase Auth and network errors into clean user-facing messages.
  * Masks internal database schemas, status codes, and stack traces.


3. SECURE PRODUCER AUTH SERVICE & RPC
------------------------------------------------------------
Implemented under lib/producer_section/auth/services/:
- ProducerAuthService (lib/producer_section/auth/services/producer_auth_service.dart)
  * Calls register_producer_profile(p_full_name) database RPC.
  * Fetches public.profiles and public.producer_profiles.
  * Validates that caller has role = 'producer' and producer_profiles exists.
  * Security Control: If authorization fails (e.g. Buyer account, Admin account, or setup incomplete), the service automatically terminates the active Supabase session (signs out) before returning the access-denied result to prevent unauthorized state retention.

- Database RPC (supabase/sql/004_fix_producer_rpc_sql_expressions.sql):
  * Executed and verified in Supabase SQL Editor.
  * Mode: SECURITY DEFINER with SET search_path = ''.
  * Caller Identity: Derived strictly from auth.uid().
  * Validates full name (2–120 characters) using standard TRIM and LENGTH.
  * Strict Role Policy: Assigns role = 'producer' for new users; allows idempotent retry for existing producers; REJECTS existing Buyer and Admin accounts (Buyer -> Producer conversion not supported in this phase).
  * Initializes producer_profiles with onboarding_status = 'not_started' and verification_status = 'unverified' via ON CONFLICT (id) DO NOTHING.


4. AUTHENTICATION SCREENS & ROUTING
------------------------------------------------------------
- ProducerLoginScreen (lib/producer_section/auth/producer_login_screen.dart):
  * Low-literacy friendly layout with high-contrast inputs and show/hide password toggles.
  * Fully wired to AuthService and ProducerAuthService.
  * On success, routes to '/producer_home' (ProducerPlaceholderScreen).

- ProducerSignupScreen (lib/producer_section/auth/producer_signup_screen.dart):
  * Fields: Full Name, Email, Password, Confirm Password.
  * On submission: signs up via Supabase Auth, invokes register_producer_profile RPC, and routes to '/producer_home'.

- ProducerPlaceholderScreen (lib/producer_section/home/producer_placeholder_screen.dart):
  * Displays "Producer Account Ready", user account details (Email, Role, Onboarding Status, Verification Status), and Sign Out action.

- AppRouter Integration (lib/core/routes/app_router.dart):
  * AppRouter.initialRoute ('/') -> RoleSelectionScreen
  * AppRouter.buyerAuthRoute ('/buyer_auth') -> AuthScreen
  * AppRouter.producerLoginRoute ('/producer_login') -> ProducerLoginScreen
  * AppRouter.producerSignupRoute ('/producer_signup') -> ProducerSignupScreen
  * AppRouter.producerHomeRoute ('/producer_home') -> ProducerPlaceholderScreen
