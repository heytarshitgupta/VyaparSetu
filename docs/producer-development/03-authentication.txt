1. SHARED AUTHENTICATION SERVICE
------------------------------------------------------------
Implemented under lib/core/auth/:
- AuthService (lib/core/auth/auth_service.dart)
  * Singleton wrapping Supabase Auth operations using SupabaseService.client.
  * Methods: signUpWithEmail, signInWithEmail, signOut, currentUser, currentSession, authStateChanges stream.
  * Uses the Supabase publishable key only. Zero service-role keys.

- AuthExceptionHandler (lib/core/auth/auth_exception_handler.dart)
  * Sanitizes Supabase Auth and network errors into clean user-facing messages.
  * Masks internal database schemas, status codes, and stack traces.


2. SECURE PRODUCER AUTH SERVICE & RPC
------------------------------------------------------------
Implemented under lib/producer_section/auth/services/:
- ProducerAuthService (lib/producer_section/auth/services/producer_auth_service.dart)
  * Calls register_producer_profile(p_full_name) database RPC.
  * Fetches public.profiles and public.producer_profiles.
  * Validates that caller has role = 'producer' and producer_profiles exists.
  * Security Control: If authorization fails (e.g. Buyer account, Admin account, or setup incomplete), the service automatically terminates the active Supabase session (signs out) before returning the access-denied result to prevent unauthorized state retention.

- Database RPC (supabase/sql/002_producer_auth_rpc.sql):
  * Executed successfully in Supabase SQL Editor.
  * Mode: SECURITY DEFINER with SET search_path = ''.
  * Caller Identity: Derived strictly from auth.uid().
  * Validates full name (2–120 characters).
  * Strict Role Policy: Assigns role = 'producer' for new users; allows idempotent retry for existing producers; REJECTS existing Buyer and Admin accounts (Buyer -> Producer conversion not supported in this phase).
  * Initializes producer_profiles with onboarding_status = 'not_started' and verification_status = 'unverified' via ON CONFLICT (id) DO NOTHING.
